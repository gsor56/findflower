Common
questions

Is it really free right now?

Yes. Identifying flowers in your browser costs nothing and needs no account, and that is true for the whole Beta.

Is the free scanner a weaker model?

No. Flora-Flash answers a free scan today and would answer a paid one too, and nothing is held back to sell later. Flora-Micro is a second, smaller engine you can switch to on purpose because it never uploads your photo, which is a different trade rather than a downgrade. Both are described here.

Why does a free project have a pricing page?

Because the server behind the API costs money to run, and saying so early is more honest than a surprise later. What this project is explains the rest of it.

When will the prices be set?

Alongside the hosted API, which is not finished. It will be announced on this page, with notice, before anything changes for anyone already using it.

Do I need a plan for the direct endpoint?

No plan, but you do need to sign in: the endpoint wants a bearer token and refuses requests without one. Paid plans will cover the full hosted API and its keys when they launch. The API page has the details.
