FindFlower API (Beta)

One endpoint. POST an image, get back a species name and a confidence score. The model is a fine-tuned Vision Transformer covering 116 flower species.

Endpoint

A single route. No SDK required.

POST https://api.findflower.me/v1/identify
Send multipart/form-data with a single file field. Maximum 8 MB per image; JPEG, PNG, and WebP are accepted.

Example request

Your key travels in the Authorization header, never the query string.

curl -X POST https://api.findflower.me/v1/identify \
  -H "Authorization: Bearer ff_live_YOUR_KEY_HERE" \
  -F "file=@sunflower.jpg"

Example response

200 OK · application/json

{
  "flower": "common sunflower",
  "confidence": 0.99
}

confidence is a softmax probability between 0 and 1. Treat anything below 0.40 as "no confident match" rather than a weak answer — the model always returns its best guess, even for an image that contains no flower at all.

Status codes

Every non-200 carries a JSON error field.

200Identification returned.
400Missing file field, or the image could not be decoded.
401Missing or invalid API key.
413Image exceeds 8 MB.
429Rate limit exceeded for your key.
503Model is cold-starting. Retry after a few seconds.

Requesting access

Keys are issued manually during the beta. The model runs on a single free-tier instance, so capacity is genuinely limited and access is granted case by case. Tell me what you're building and I'll get back to you.
